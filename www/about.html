About the Server Architecture

This web server was developed in accordance with the CS631 Advanced Programming in the UNIX Environment (APUE) course syllabus.

RFC 1945 HTTP/1.0 Implementation

The server enforces strict compliance with the HTTP/1.0 specification, including:

  • Supported request methods: GET and HEAD. Any unimplemented method yields a 501 Not Implemented response.
  • Mandatory response headers: Date, Server, Last-Modified, Content-Type, and Content-Length.
  • Date headers formatted to RFC 1123 GMT standards via strftime.
  • Conditional GET handling using If-Modified-Since, avoiding unnecessary payload transfers with 304 Not Modified.

UNIX Systems Programming Concepts

  • Dæmonization: Detaches from terminal via dual fork(), setsid(), chdir("/"), umask(0), and redirection of standard file descriptors.
  • Concurrency: Multi-process model forking worker processes per client connection with non-blocking SIGCHLD reaping.
  • User Directories: Resolves ~username/ requests to /home/<user>/public_html/ via POSIX getpwnam().
  • Auto-indexing: Dynamic HTML directory index generation with opendir() and readdir().
  • CGI 1.1: Process isolation using pipe(), dup2(), and execve().
