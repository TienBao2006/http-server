APUE HTTP/1.0 Server

CS631 Advanced UNIX Web Server

Strict POSIX C99 compliance, multi-process fork architecture, CGI 1.1 execution, and secure directory navigation.

⚡ Multi-Process Model

Uses fork() on incoming connections with asynchronous non-blocking SIGCHLD zombie process reaping via waitpid(-1, WNOHANG).

🛡️ Traversal Protection

Strict path sanitization and canonical realpath() boundaries prevent .. directory traversal attacks.

🔄 HTTP Caching

Full support for If-Modified-Since request header returning 304 Not Modified with zero body transfer.

⚙️ CGI 1.1 Support

Dynamic execution of CGI programs using pipe(), fork(), dup2(), and execve() with standard environment variables.
